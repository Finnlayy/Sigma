Fixed the Server-Sent Events stream inside `SystemHealthPanel` which previously suffered from fragile raw `EventSource` connections and silent payload parsing failures.

**Changes Details:**
- Implemented custom exponential backoff reconnect logic. Disabled native aggressive reconnect by closing on `onerror` and queueing exponential `setTimeout`.
- Added strict `TelemetrySchema` using `zod` for fail-closed parsing. Malformed payload streams are explicitly caught and logged to `console.error` rather than failing silently.
- Verified robust cleanup in the `useEffect` destructor, avoiding orphaned timers or leaked sockets.

**Latency / Traces:**
- Benchmark tests via `test_market_feed_ws.py` maintain sub-millisecond dispatch stability under load.
- Simulated protocol event traces show smooth degradation to backoff polling with no orphaned zombie connections during simulated network instability.
