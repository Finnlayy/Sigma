## 2 · M8 State Engine

Redis key: `m8:state:{strategy_id}` · example base_budget $50

| State | Multiplier | Enter | Exit |
|-------|------------|-------|------|
| ACTIVE | 1.0 | Default / budget >50% base | → THROTTLED at ≤50% base OR 3 EOD days PF < 1.0 |
| THROTTLED | 0.5 | Budget ≤50% OR 3 low-PF EODs | → ACTIVE when budget >50%; → QUARANTINED at $0 or 7 low-PF days |
| QUARANTINED | 0.0 | Budget $0 OR 7 consecutive EOD PF < 1.0 | Explicit re-promotion only |
| RETIRED | — | 4 weeks Shadow without GA recalibration | Terminal |

### Vault & Profit Sweep (v1.2.0)
